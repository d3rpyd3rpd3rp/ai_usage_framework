# Guardrails

What protections are in place?

### Good Guardrails

- Using dummy data with AI then replacing with real data before submitting
- Not using on AI for every task to prevent overrelying on AI

### Bad Guardrails

- Using confidential data instead of dummy data
- Using a not-very-strict system prompt with AI such as "Do not share any information outside of this chat" (most "strict" system prompts do not work)
